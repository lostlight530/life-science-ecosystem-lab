## QUALIFY → EXECUTE → EVALUATE

Three different units can change independently:

1. **Source/metadata identity**: Git revisions, collection provenance, snapshot and the selected-text classification may change without novel source prose
2. **Knowledge projection and event identity**: digests, `SOURCE_MATCH` references, per-topic transition and the accepted Event chain can legitimately change; here the `workflow-monitoring` transition is `UPDATED` while the event's `change_kind` is `DOCUMENT_TEXT_UNCHANGED`
3. **Scientific claim and external authority**: neither a changed knowledge digest nor an `APPLIED` Receipt supplies experimental ground truth, independent biological replication or third-party certification

The same unit discipline applies to scheduled operations. On November 23 UTC, nominal daily/knowledge/continuity Cron times and actual `created_at` differ by 08:06:20, 09:46:05 and 10:35:59. These are exact **observable clock differences**, not a measured GitHub queue or outage root cause; the scheduled Jobs and post-push world-line checks succeeded.

Keep old visible-Run snapshots when the live API drops failed Run identities: four historical failed parent Runs now return 404, without falsifying their earlier frozen witness. A cancelled parent can also contain a failed Job; parent status alone is an insufficient quality metric.
