## Responsibility and current status

**Status: `LOCAL_PREPARATION_ONLY` / `OSF_REGISTRATION_NOT_VERIFIED`.** These documents are maintained in GitHub and have not been submitted to, approved by, time-stamped as, or assigned an OSF Registration or preregistration identifier. They are *project-owned research-planning aids*, not an official Center for Open Science form, OSF registration schema, institutional certification, or public scientific result

The laboratory is a research-software-methodology project, **not a single scientific study**. Its invariant DEFINE → PIN → QUALIFY → EXECUTE → EVALUATE → AUDIT → REVIEW → REPLAY method, three independent software assets and optional experimental Framework support **replaceable cases**. A study must be separately specified before any genuinely prospective plan can be preregistered

## Distinguish three different records

| Record | Authority and appropriate disposition |
| --- | --- |
| Repository Git history and software evidence since 2026-10-16 | Historical, already observed engineering data: [source-pinned taxonomy](../taxonomy/README.md), dated [provenance](../provenance/README.md), real accepted `data/`. **Not preregistered retroactively** |
| Future falsifiable study-specific protocol | Draft a [study-specific research plan](RESEARCH_STUDY_PLAN_TEMPLATE.md), fix its source and timing **before** the selected new study's relevant data collection or analysis, and select an actual OSF template |
| An actual OSF Registration | Provider-owned status/ID, registration creation and any subsequent changes must be verified in OSF; a GitHub document, CodeMeta record, DOI for software, WorkflowHub registration or CI badge is **not** an OSF registration |

If registering work already underway or concluded, disclose that status and date honestly; do not label it prospective preregistration after outcomes have been observed

## Source and packaging boundary

Only include research-plan material relevant to the specified study, its cited frozen version, exact inclusion/exclusion criteria, measures, analysis decisions, contingencies and material deviations. Do **not** upload the whole repository as if it were a study plan, and do not attach production `data/`, private Agent activity, unrelated personal information or original upstream copyrighted material without separate rights and review

The authoritative ongoing software lives on GitHub. Attachments to an OSF Registration have distinct update constraints; use OSF's registration-update process and appropriate links to later research outputs, not silent replacement of an original plan. The external service controls review, acceptance, metadata and DOI

## Platform transition verified from official help, 2026-11-07

OSF **Projects** are transitioning: creation of new Projects/Components ends **2026-11-16**; existing Projects become read-only **2027-02-19**. OSF **Registrations** and **Preprints** continue. Therefore this lab must not assume OSF Projects will remain the editable source-of-truth or that one must create a Project before a Registration. GitHub retains versioned software and the proposed study may use the direct Registration workflow
