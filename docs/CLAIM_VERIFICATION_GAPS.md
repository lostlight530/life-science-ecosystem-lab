## Decision rights and four incompatible truth levels

**Software correctness:** versioned code, actual test runner, meaningful negative controls and exact machine status. Passing is bounded by the tested contract

**Evidence validity:** immutable source/file, exact bytes or reproducible digest, separate retrieval time, relationship to the observed output and independent verification

**Method applicability:** operating conditions, comparator choice, exclusion and abstention criteria, sample grain and domain-specific limitations. Failure and inapplicability are acceptable scientific outcomes

**Scientific truth:** independent domain oracle, actual empirical records, uncertainty, peer/human review, and dissent. Neither software PASS nor a GitHub merge satisfies this obligation

External institutional registration and permission are **another authority**: only the corresponding institution may define its official specifications, acceptance, account rights and authentication

The invariant **DEFINE → PIN → QUALIFY → EXECUTE → EVALUATE → AUDIT → REVIEW → REPLAY** method applies to these individual claim reviews; outcomes and source IDs must stay distinct. New decisions require an independently inspectable source/revision, negative control, reviewer authority and falsification condition. This Markdown cannot change software or data acceptance.
