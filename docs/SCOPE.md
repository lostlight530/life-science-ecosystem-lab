# Scope and assurance boundaries

## In scope

- Deterministic validation of non-sensitive JSON research records
- Immutable source identity for GitHub-hosted research workflows
- Versioned schemas, examples, tests, provenance, and recovery information
- Standards-aware metadata and calibrated records for the externally verified WorkflowHub workflow, maintainer-observed private LifeMonitor enrollment, bio.tools identity, OpenEBench synchronization and Zenodo release
- Evidence-based maintenance of repository documentation, citation and reusable Life Science infrastructure templates
- Experimental, independent life-sciences cross-domain **software-engineering** contracts, with synthetic negative tests and no biological interpretation

## Out of scope

- Biological interpretation or efficacy claims
- Clinical use, diagnosis, treatment, or medical advice
- Processing of credentials, personal health information, or controlled data
- Claims of registry acceptance or monitoring before external verification
- New dataset publication, paper publication or citation-impact analysis; the existing software and workflow DOIs are recorded only as verified identities
- Changes to the existing eleven-repository system

Example records are synthetic fixtures for software verification and are not a scientific dataset
