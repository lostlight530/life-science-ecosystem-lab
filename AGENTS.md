# External Agent participation · optional, proposal-only

This repository has **three established independently callable research software assets** and an independent experimental [software-engineering Framework](framework/README.md) at repository root: native knowledge Workflow under `.github/`, the independent `ls-evidence` Tool under `evidence/`, and the independent `ls-bio` protein data-processing tool under `bio_tool/`. The separate Framework is not an Agent runtime and has no mandatory dependency on these three assets. No agent framework, skill, model account, API key, or external scheduler is necessary to run any of them.

Before assuming a current repository state from old reports, distinguish the [dated full Git/PR/Actions provenance census](docs/provenance/README.md) and [origin-to-present reconstruction](docs/REPOSITORY_HISTORY_AND_PROVENANCE.md) from **current remote main** and accepted `data/`. [Open claims](docs/CLAIM_VERIFICATION_GAPS.md) retain unmerged changes, failed/cancelled runs, predecessor uncertainties and institutional status limits. Historical snapshot documents have **no** execution, registry, approval or production-write authority.

Before working, read [Architecture](docs/ARCHITECTURE.md), [Agent collaboration](docs/AGENT_COLLABORATION.md), and [Verification boundaries](docs/VERIFYING_RESULTS.md). For durable accepted state, `data/` and its Git commit/receipts are authoritative, not an Agent answer or temporary workspace. The current native topic IDs, aliases, thresholds and approved sources belong exclusively to `evidence/profiles/topics.json` and `evidence/profiles/sources.json`.

**Protein field case:** the [protein structure prediction pilot](docs/PROTEIN_STRUCTURE_FIELD_DEMO.md) and [pinned Agent handoff](.github/agent-handoff/protein-structure-2026-10-17.json) demonstrate a proposal-only external Agent using isolated native source/topic profiles, with no direct production authority.

**Agent provenance and role:** Different Agents may contribute research evidence, critical interpretation and executable improvements through normal PRs. Agent identity may be **self-declared** using optional `proposer: {agent_label, execution_surface, assertion: "SELF_DECLARED"}` in handoff/research-case JSON; this is not GitHub identity verification. See the [Agent cohort research case](docs/AGENT_CLUSTER_RESEARCH_CASE.md) and [review decision ledger](docs/AGENT_REVIEW_DECISIONS.md). Original observations and independent maintainer reviews must remain distinguishable.

**Daily institutional/project boundaries:** Official public service pointers in [checks/institutional/](checks/institutional/README.md) and repository-owned custom files in [checks/project/](checks/project/README.md) have separate manifest/report/artifact ownership. Neither plane may publish external registry or account access claims. See [Daily Self-Check](docs/DAILY_SELF_CHECK.md).

**When an external Agent conducts a new online research session:** use the independent [research SOP](.github/agent-handoff/SOP.md) and [task template](.github/agent-handoff/TASK_TEMPLATE.md). Return a human-readable evidence review and, if useful, a `EXTERNAL_AGENT_RESEARCH_HANDOFF` JSON proposal. Run `ls-evidence validate-handoff --input <file> --topics evidence/profiles/topics.json` before a proposed PR. This only validates the proposal envelope.

The Agent may independently search the web, use its own scheduling (e.g. Jules or GPT tasks), review external workflow/tool outputs, propose code/doc/source-profile edits, and submit changes for review. **Do not** automatically add discovered sources to the native registry, alter topic policy, promote findings to scientific truth, edit accepted `data/`, invoke `persist=true`, or assert external registration on the strength of an Agent report. Accepted production writes remain governed by the native workflow.

Keep local scratch under ignored `build/` or `.agent-work/`; never commit tokens, session logs, caches, internal deliberation, or downloaded private research materials. Preserve accepted snapshots, immutable provenance, receipts and field evidence, even if they look like generated files.
